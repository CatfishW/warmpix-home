# 暖像素家园 WarmPix Home

放下家之锚就安了家，用归家罗盘和触屏友好的家园界面回家，还有玩家互传、上门做客和死亡返回。

- Minecraft：26.3
- 加载器：NeoForge 26.3.0.23-beta 或更高
- 客户端与服务端都需要安装
- 无其他模组前置
- 语言：简体中文 / English

## 下载

请到 [Releases](../../releases) 页面下载 jar（版本 1.3.0）。

## 内容

- 家之锚（可合成）：放下即成为你的一个家；只有主人和管理员能拆，防爆、防活塞，拆除时家会一起移除
- 归家罗盘（可合成）：右键打开家园界面，潜行右键回到默认的家，指针指向默认的家
- 家园界面：查看全部的家，在此安家、改名、设为默认、删除；支持点按、拖动滚动，适合触屏
- 指令：/sethome [名称]、/home [名称]、/delhome、/renamehome <旧名> <新名>、/homes，家名可用中文（1–16 字）
- 回家规则：站稳倒计时，移动或受伤会取消；冷却时间、每人家数量上限；目的地被堵住、悬空或有岩浆时取消传送并保留家
- 玩家互传：/tpa、/tpahere，聊天里点击接受或拒绝，/tpacancel 撤回，/tptoggle 关闭他人请求；请求有效期与冷却
- 上门做客：/visit <玩家> 申请参观对方的小屋，对方同意后传送过去；可用 /visit sethome <家名> 指定接待的地点
- /back 返回最近一次死亡地点，附近找安全落脚点
- 服务端权威，配置文件 config/warmpix_home.json：家上限、倒计时、冷却、是否允许跨世界、禁止的维度等；管理员可改上限、重载配置

## 说明

- 本仓库只用于发布 jar，不含源码。
- jar 里还带有一套给家园世界自动修路、布置村镇的管理员功能，需要服主另外配置专用维度才会启用，不配置时不生效。
